## Что это

Переписанный под Windows аналог Applio: берёт звук с микрофона, прогоняет через RVC-модель и отдаёт в виртуальный микрофон, который видят Discord, OBS, игры и любые другие программы.

Ничего настраивать вручную не нужно — Python, PyTorch, бэкенд и базовые модели программа скачивает и устанавливает сама при первом запуске.

## Возможности

- **Один файл.** Самодостаточный `RvcVoiceChanger.exe` — .NET и Python ставить не надо.
- **Автоустановка при первом запуске.** Portable Python 3.11.9, PyTorch (CUDA при наличии NVIDIA-карты с драйвером ≥ 525, иначе CPU с предупреждением), RVC-бэкенд и модели rmvpe/contentvec. Повторно ничего не качается — ведётся штамп установки.
- **Реальное время.** WASAPI-захват, вывод в виртуальный микрофон и самопрослушку, индикаторы уровня и отображение задержки.
- **Парсер моделей HuggingFace.** Список авторов с пагинацией, скачивание с прогрессом и докачкой, автоматическая распаковка и проверка `.pth` + `.index`.
- **Своя библиотека моделей.** Добавление `.pth` + `.index` вручную или из ZIP, переименование, удаление.
- **Прокси.** HTTP и SOCKS5 с логином/паролем (шифруется через DPAPI), отдельные галочки для pip и HuggingFace, зеркало PyPI, кнопка «Проверить соединение». Прокси пробрасывается в дочерний Python. Логин и пароль маскируются во всех логах.
- **Самопроверка.** `vc_worker.py --selftest` проверяет torch, CUDA, librosa, faiss, transformers, pedalboard, бэкенд и наличие весов.
- **Живые логи.** Фильтр по уровню и поиск, дублирование в `logs/app-ГГГГ-ММ-ДД.log` (хранятся 14 дней).
- **Portable-режим.** Пустой файл `portable.txt` рядом с `.exe` — и все данные лежат в папке `RvcData` рядом с программой.
- **Тёмная и светлая темы.**

## Требования

| | Минимум |
|---|---|
| ОС | Windows 10/11 x64 |
| Диск | ~8 ГБ свободно (PyTorch CUDA занимает основную часть) |
| Интернет | нужен при первом запуске: скачивается 3–6 ГБ |
| GPU | NVIDIA с драйвером ≥ 525 — желательно; без GPU работает на CPU с большей задержкой |

## Быстрый старт

1. Скачайте `RvcVoiceChanger.exe` из [Releases](../../releases).
2. Запустите и дождитесь окончания автоустановки.
3. Нажмите **«Установить виртуальный микрофон»** — будет скачан и установлен бесплатный VB-CABLE (один UAC-запрос).
4. На вкладке **Модели** или **Парсер моделей** добавьте голосовую модель.
5. На вкладке **Изменение голоса** выберите модель и микрофон, задайте высоту тона и нажмите **Старт**.
6. В Discord / OBS / игре выберите микрофон **CABLE Output**.

> Кнопка **«Проверка»** позволяет услышать себя до того, как вас услышат другие.

## Как работает парсер моделей

Страница `huggingface.co/models?other=rvc` рисуется на JavaScript, поэтому используется официальный публичный API — быстрее и не ломается при редизайне.

1. `GET /api/models?filter=rvc&sort=downloads&limit=N&skip=M` — страница авторов.
2. `GET /api/models/{repo}/tree/main?recursive=true` — файлы с размерами (кэш 15 минут против rate-limit).
3. Валидным считается репозиторий, где есть **либо `.zip`, либо пара `.pth` + `.index`**. Если есть и то и другое — показывается ZIP.
4. Служебные веса отсеиваются: `hubert*`, `rmvpe*`, `fcpe*`, `contentvec*`, `pretrained*`, `D40k.pth`, `G48k.pth` и т.п. Сравнение идёт по границам слов, чтобы модели вроде «Crepes» не отсекались по подстроке «crepe».
5. Скачивание: `{repo}/resolve/main/{path}` с прогрессом, скоростью и докачкой по Range.
6. После скачивания — распаковка, поиск `.pth` и `.index`, добавление модели. При битом архиве выводится ошибка и открывается папка с файлом.

## Виртуальный микрофон

Windows не позволяет создать виртуальный микрофон из обычного приложения — нужен драйвер режима ядра, а для него EV-сертификат и аттестация Microsoft. Поэтому используется бесплатный **VB-CABLE**:

- программа пишет голос в **CABLE Input**;
- в сторонних приложениях выбирается микрофон **CABLE Output**;
- URL установщика можно переопределить настройкой `VbCableUrl`, SHA-256 архива пишется в лог.

## Где хранятся данные

```
%LOCALAPPDATA%\RvcVoiceChanger\
  runtime\
    python\   portable Python 3.11.9 + пакеты
    backend\  RVC-бэкенд + rmvpe.pt / contentvec (+ fcpe.pt, если скачался)
  models\     ваши голосовые модели
  downloads\  скачанные архивы
  logs\       журналы
  settings.json, models.json
```

Путь бэкенда прописывается в `python311._pth` относительным путём, поэтому papку рантайма можно свободно переносить.

## Тонкая настройка (`settings.json`)

| Ключ | Зачем |
|---|---|
| `PythonZipUrl` | зеркало python.org |
| `TorchIndexUrl` | индекс PyTorch |
| `PipIndexUrl` | зеркало PyPI |
| `HfEndpoint` | зеркало HuggingFace, например `https://hf-mirror.com` |
| `HfToken` | доступ к приватным и gated репозиториям (хранится через DPAPI) |
| `WeightsRepo` | репозиторий весов вместо `IAHispano/Applio` |
| `VbCableUrl` | URL установщика VB-CABLE |
| `HfSearchFilter`, `HfPageSize` | фильтр и размер страницы парсера моделей |

## Архитектура

```
WPF UI (C#) ── WASAPI захват ── блоки float32 48кГц
                                  │  TCP 127.0.0.1 (бинарные кадры)
                          vc_worker.py ── rvc.realtime.core.VoiceChanger
                                  │
            WASAPI вывод ── CABLE Input + (опционально) наушники
```

Почему Python внутри, а не чистый C#: веса RVC — это PyTorch-чекпоинты, а индексы — faiss. Порт на ONNX ломает совместимость с чужими `.pth` с HuggingFace, а именно их и качает парсер. Пользователь Python не видит — он спрятан в папке данных.

## Сборка из исходников

```powershell
cd RvcVoiceChanger
dotnet restore
dotnet publish src/RvcVoiceChanger/RvcVoiceChanger.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Результат: `src\RvcVoiceChanger\bin\Release\net8.0-windows\win-x64\publish\RvcVoiceChanger.exe` (~70–90 МБ).

Подробности и структура проекта — в [BUILD.md](BUILD.md).

## Известные особенности

- Первый запуск требует интернета и качает 3–6 ГБ.
- Без NVIDIA GPU ставится CPU-версия PyTorch: работает, но задержка выше — ставьте размер чанка от 192.
- Антивирус может ругаться на неподписанный single-file exe.
- `fcpe` опционален: если не скачался, выводится предупреждение, остальное работает.

## Лицензия и ответственность

Проект использует сторонние компоненты (RVC-бэкенд, PyTorch, VB-CABLE) на условиях их собственных лицензий. Не используйте клонирование голоса для обмана, выдачи себя за других людей или иных незаконных целей.
